# YugeSavers prototype (baseline)

Original source of a supermarket app prototype, kept here as the starting point.
Left out of this commit on purpose: the vendored Bootstrap CSS, the product photos
(downloaded from loremflickr.com with no recorded licence) and the image scripts,
so pages on this commit render without images or layout utilities.
The reworked version lives on the `ui-ux-improvements` branch.
